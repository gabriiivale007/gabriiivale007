## About me

I'm a developer at **Software Engineering Italia** and a student at the **University of Catania**. I enjoy learning by building things, especially projects that combine software, artificial intelligence and electronics.

My interests range from **local AI and automation** to **autonomous robots, embedded systems and 3D prototyping**.

- **AI:** agents, LLM applications, RAG systems and local models.
- **Software:** web and mobile apps, APIs and tools for everyday tasks.
- **Hardware:** ESP32, Raspberry Pi Pico, sensors and device communication.
- **Robotics:** pathfinding, computer vision and autonomous navigation.
